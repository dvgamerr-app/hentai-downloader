Hentai Downloader queues galleries from e-hentai.org and exhentai.org and saves each one into its own tidy folder, so you stop saving pages one by one in a browser.

Hentai Downloader จัดคิวมังงะจาก e-hentai.org และ exhentai.org แล้วบันทึกลงโฟลเดอร์ของแต่ละเรื่อง ไม่ต้องเปิดเบราว์เซอร์เซฟรูปทีละหน้าอีกต่อไป

Built for long queues

ออกแบบมาสำหรับคิวยาวๆ

Everything the app does is about getting a pile of galleries onto disk with the least babysitting.

ทุกอย่างในแอปมีไว้เพื่อให้ได้มังงะทั้งกองลงดิสก์โดยไม่ต้องเฝ้า

Clipboard watching

ตรวจจับ clipboard

Copy a gallery link anywhere and the app picks it up.

copy ลิงก์จากที่ไหนก็ได้ แอปจับให้เอง

Multi-line paste

วางหลายบรรทัด

Paste a list, one link per line, and all of it joins the queue.

วางลิสต์บรรทัดละลิงก์ แล้วเข้าคิวทั้งหมด

No Credits spent

ไม่เสีย Credits

Fetches the normal viewer images, not the paid originals.

โหลดรูปจากหน้า viewer ปกติ ไม่ใช่ไฟล์ original ที่เสียเงิน

Safe to re-run

รันซ้ำได้

Pages already on disk are skipped, so only the missing ones are fetched.

หน้าที่มีอยู่แล้วจะถูกข้าม โหลดเฉพาะที่ขาด

One folder per gallery

หนึ่งเรื่องหนึ่งโฟลเดอร์

Files are numbered by page inside a folder named after the gallery.

ไฟล์ตั้งชื่อเป็นเลขหน้า อยู่ในโฟลเดอร์ชื่อเดียวกับเรื่อง

Auto update

อัปเดตอัตโนมัติ

Installed builds check GitHub Releases and ask before restarting.

Up and running in four steps

เริ่มใช้งานใน 4 ขั้นตอน

No account on this site, no configuration file.

ไม่ต้องสมัครอะไรกับเว็บนี้ ไม่ต้องแก้ไฟล์ config

  1. Installติดตั้งDownload hentai-downloader-<version>-setup.exe from the latest release and run it.โหลด hentai-downloader-<version>-setup.exe จาก latest release แล้วรัน
  2. Add galleriesเพิ่มมังงะPaste a link like https://e-hentai.org/g/1234567/abcdef0123/ and press Enter. Paste many lines to add many.วางลิงก์ เช่น https://e-hentai.org/g/1234567/abcdef0123/ แล้วกด Enter วางหลายบรรทัดเพื่อเพิ่มหลายเรื่อง
  3. Pick a folderเลือกโฟลเดอร์Click the folder button and choose where files are saved.กดปุ่มโฟลเดอร์แล้วเลือกที่เก็บไฟล์
  4. DownloadDownloadPress Download. Avoid browsing the same site meanwhile, it can make some images fail.กด Download ระหว่างโหลดไม่ควรเปิดเว็บเดียวกัน เพราะรูปบางรูปอาจโหลดไม่สำเร็จ

Prefer to build it yourself? You need Bun 1.3.

อยากรัน build เอง? ต้องมี Bun 1.3

bun install --frozen-lockfile
bun run build:win
